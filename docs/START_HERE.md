# Empezar aquí

- Para leer el guion, repartir la exposición y seguir la demostración, abre la [guía completa para tres personas](PRESENTACION_TRES_PERSONAS.md).
- Para mostrar el trabajo desde cualquier computador o celular, abre el [panel público](https://aci606-cloud-fleet-sebit44s.onrender.com/dashboard) y pulsa **Iniciar demostración**.
- Para realizar las comprobaciones del ejercicio, despliega **Pruebas para la presentación** dentro del panel.
- Para estudiar los resultados de entrenamiento, abre el [reporte del modelo](../reports/MODEL_REPORT.md).
- Para preparar un entorno de desarrollo, sigue el [README](../README.md).

La guía y el código están publicados en este repositorio. El panel se ejecuta en Render y el historial se conserva en PostgreSQL en Neon.
